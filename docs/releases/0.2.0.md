# Scrabble Solver 0.2.0

Scrabble Solver 0.2.0 expands the original rack helper into a complete
board-aware desktop assistant. It can track both players' visible moves,
validate connected words, and rank legal placements by their full turn score.

## Highlights

- A selectable 15-by-15 board with the standard premium-square layout.
- Ranked legal moves with exact coordinates, direction, cross-word scoring,
  blank optimization, premiums, and seven-tile bingo bonuses.
- Dedicated opponent-move recording that never reads or changes your rack.
- Multi-turn board history with undo and new-game reset.
- A bundled 169,266-word ENABLE 2K dictionary and remembered custom dictionary
  selection.
- A portable Windows x86-64 package containing GTK and an installable Debian 13
  amd64 package using system GTK dependencies.
- Expanded unit, integration, GTK workflow, and full-dictionary performance
  coverage on Windows UCRT64 and Debian 13.

## Downloads

Choose the package for your system from the assets attached to the GitHub
release:

- **Windows x86-64:** `scrabble-solver-0.2.0-windows-x86_64.zip`
- **Debian 13 amd64:** `scrabble-solver_0.2.0-1_amd64.deb`

The Windows build is portable: extract the entire application archive and run
`bin\scrabble_solver.exe`. On Debian, install the downloaded package with:

```sh
sudo apt install ./scrabble-solver_0.2.0-1_amd64.deb
```

See the
[installation and troubleshooting guide](https://github.com/JoJoKorok/scrabble-solver/blob/v0.2.0/docs/INSTALLATION.md)
for complete setup, update, removal, and dictionary instructions.

## Playing successive turns

Enter your current rack and select **Find words**. Place one of the ranked
suggestions, then replace the rack entry after drawing new tiles. When the
opponent plays, select their word's first square and use
**Record opponent move**. Mark any newly placed blank squares before recording
their move. The board and undo history then remain synchronized for the next
search.

## Important notes

- ENABLE 2K is an open word-game dictionary, not the current NASPA Word List or
  Collins Scrabble Words list. Accepted words may differ from a commercial game
  or tournament dictionary.
- Rack contents are entered manually and are not reduced or refilled
  automatically.
- Board state lasts for the current application session and is not yet restored
  after the app closes.
- Searches currently run synchronously without cancellation or progress
  reporting.
- The portable Windows package is not currently code-signed and may receive a
  Windows reputation warning when first downloaded.
